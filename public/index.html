CeloRemit

CeloRemit is an AI remittance agent on Celo that turns natural-language chat into cross-border transfers through Telegram and WhatsApp. It supports wallet-signed non-custodial transfers, fee comparison, recurring payments, receipts, schedules, and Mento-powered routing.

Test on Telegram Open Wallet Page View GitHub

What It Does

  • Parses remittance requests in natural language
  • Supports Telegram and WhatsApp user flows
  • Uses wallet sign-in and user-approved execution
  • Handles recurring transfers and schedules
  • Routes value through Celo stable assets and Mento

How to Test

  1. Open Telegram and search @CeloRemitBot
  2. Send /start
  3. Send check balance
  4. Connect and sign with your wallet
  5. Try a transfer or run Show schedules
